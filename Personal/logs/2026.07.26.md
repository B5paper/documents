* numpy 如何计算中位数

    在 NumPy 中，计算中位数最直接的方法是使用 **`numpy.median()`** 函数。

    以下是详细的使用方法、参数说明和注意事项：

    ### 1. 基本用法（一维数组）

    ```python
    import numpy as np

    data = np.array([1, 3, 5, 7, 9])
    median_value = np.median(data)
    print(median_value)  # 输出：5.0
    ```

    **注意：** 返回结果总是 **浮点数**（float），即使输入是整数。

    ---

    ### 2. 指定轴向（多维数组）

    对于二维或多维数组，可以通过 `axis` 参数指定计算中位数的方向。

    ```python
    data = np.array([[1, 2, 10],
                     [4, 5, 6]])

    # 计算全局中位数（所有元素）
    print(np.median(data))          # 输出：4.5

    # 按列计算（axis=0）：每列的中位数
    print(np.median(data, axis=0))  # 输出：[2.5 3.5 8.0]

    # 按行计算（axis=1）：每行的中位数
    print(np.median(data, axis=1))  # 输出：[2.0 5.0]
    ```

    ---

    ### 3. 保持维度（keepdims）

    如果希望计算结果保留原来的维度（方便广播运算），可以设置 `keepdims=True`：

    ```python
    data = np.array([[1, 2, 3],
                     [4, 5, 6]])
    result = np.median(data, axis=0, keepdims=True)
    print(result.shape)  # 输出：(1, 3)
    ```

    ---

    ### 4. 处理偶数个元素

    当数据个数为偶数时，`np.median` 默认取中间两个数的**平均值**：

    ```python
    data = np.array([1, 2, 3, 4])
    print(np.median(data))  # 输出：2.5 (即 (2+3)/2 )
    ```

    ---

    ### 5. 掩码数组（忽略缺失值）

    如果你有带 `NaN` 的数据，普通的 `np.median` 会返回 `NaN`。此时需要使用 **`np.nanmedian`**：

    ```python
    data = np.array([1, 2, np.nan, 4])
    print(np.median(data))      # 输出：nan
    print(np.nanmedian(data))   # 输出：2.0 （忽略 nan 后排序为 [1,2,4]，中位数为2）
    ```

    ---

    ### 6. 替代方法（适用于特定场景）

    虽然 `np.median` 是最常用的，但你也可以使用：

    - **`np.percentile(data, 50)`**：计算第 50 百分位数，结果与中位数完全一致。
    - **`np.sort(data)[len(data)//2]`**：手动排序后取值（但仅适用于奇数个元素且不处理平均值的情况，不推荐）。

    ---

    ### 总结对比

    | 函数 | 适用场景 |
    | :--- | :--- |
    | `np.median(arr)` | 普通数组，快速计算中位数 |
    | `np.nanmedian(arr)` | 数据中包含 `NaN` 缺失值时 |
    | `np.percentile(arr, 50)` | 需要统一使用百分位数接口时 |

* 详细讲讲 fnirs 数据预处理过程中的 头皮耦合指数（SCI）

	**头皮耦合指数（Scalp Coupling Index, SCI）**是fNIRS数据预处理中一个核心的信号质量指标，用于量化光源-探测器这个“通道”与头皮之间的光学耦合好坏。它的核心思想很巧妙：**利用心脏搏动作为“天然信号源”来检验探头的接触质量**。

	### 🧠 核心原理：为什么心跳能反映耦合质量？

	1.  **生理基础**：心脏每次搏动都会引起头皮血管的血容量发生微小、规律性的变化。这个生理信号会同步地影响到同一通道下**两个不同波长**（通常是760nm和850nm）的近红外光检测信号。

	2.  **指标逻辑**：
		*   **良好耦合**：如果探头与头皮接触紧密，这个由心跳引起的微弱光学信号就能被清晰地捕捉到。此时，**两个波长信号中的“心跳成分”会呈现出高度同步、步调一致的起伏**（即高度相关）。
		*   **不良耦合**：如果探头被头发阻挡或接触不良，信号会变得嘈杂微弱，心跳成分被噪声淹没。此时，两个波长信号中的“心跳成分”之间就没有明显的相关性。

	3.  **数学定义**：SCI在数学上被定义为，在对原始光强信号进行**带通滤波**（通常保留0.5-2.5Hz或0.7-1.5Hz的心跳频段）和**归一化**后，同一通道两个波长信号之间的**零时滞皮尔逊相关系数**（或交叉相关值）。SCI值介于0到1之间，值越接近1，表示耦合越好。

	### 📊 如何使用与解读SCI？

	在实际的数据分析流程（如MNE-Python）中，SCI的应用通常遵循以下步骤和准则：

	*   **计算与阈值**：为每一个通道计算一个SCI值。一个**常用的经验阈值是0.7**，通常认为SCI > 0.7的通道信号质量是可接受的。低于此阈值的通道会被标记为“不良通道”，在后续分析中被排除（称为“通道剪除”）。
	*   **两种计算模式**：
		*   **静态SCI**：计算整个实验记录时长的SCI值，用于剔除从头到尾质量都很差的通道。
		*   **动态/窗口化SCI**：将数据切分成连续的时间窗口（例如每5-10秒），在每个窗口内计算SCI。这可以监测探头在实验过程中是否因被试运动而偶发性地脱离，从而标记出特定时间段内的“坏段”。

	### 💡 注意事项与变体

	*   **数据输入**：不同软件工具包对输入数据类型有不同要求。例如，Pollonini等人原始论文中的SCI是计算在原始强度信号上的，而**MNE-Python等流行工具包则要求输入“光密度（Optical Density, OD）”数据**。使用时需注意其具体的文档说明。
	*   **配对策略**：在MNE-Python的某些实现中，对于包含两个以上波长的设备，会计算同一通道内所有波长对之间的相关性，并**取其中的最小值作为该通道的SCI**，这是一种更保守的评估方式。

	SCI是保障fNIRS数据质量的第一道关卡。通过利用心跳这一内源性信号，它能高效地识别并剔除受运动伪影和不良接触影响的“坏通道”，为后续的血流动力学响应分析奠定可靠的基础。

* python 中如何将 list 中的 np.int64 元素转换成 python 原生数据类型？

	在 Python 中，将 list 中的 `np.int64` 元素转换为 Python 原生 `int` 类型，有几种常用方法。

	---

	## 方法 1：使用列表推导式 + `int()`（最推荐）

	```python
	import numpy as np

	# 示例列表
	arr = [np.int64(1), np.int64(2), np.int64(3)]

	# 转换
	result = [int(x) for x in arr]

	print(result)        # [1, 2, 3]
	print(type(result[0]))  # <class 'int'>
	```

	**优点**：简单、直观、速度快。

	---

	## 方法 2：使用 `map()` 函数

	```python
	import numpy as np

	arr = [np.int64(1), np.int64(2), np.int64(3)]

	result = list(map(int, arr))

	print(result)  # [1, 2, 3]
	```

	**优点**：代码简洁，适合函数式编程风格。

	---

	## 方法 3：如果整个列表是 NumPy 数组，直接用 `.tolist()`

	```python
	import numpy as np

	# 如果数据本身是 NumPy 数组
	np_arr = np.array([1, 2, 3], dtype=np.int64)

	# 直接转为 Python 原生 int 列表
	result = np_arr.tolist()

	print(result)        # [1, 2, 3]
	print(type(result[0]))  # <class 'int'>
	```

	**优点**：最高效，专门为 NumPy 设计。

	---

	## 方法 4：处理嵌套列表（多维情况）

	```python
	import numpy as np

	arr = [[np.int64(1), np.int64(2)], [np.int64(3), np.int64(4)]]

	# 递归转换
	def convert_to_native(obj):
		if isinstance(obj, list):
			return [convert_to_native(item) for item in obj]
		elif isinstance(obj, np.integer):
			return int(obj)
		else:
			return obj

	result = convert_to_native(arr)
	print(result)  # [[1, 2], [3, 4]]
	```

	---

	## 注意事项

	| 场景 | 推荐方法 |
	|------|----------|
	| 普通 list 包含 `np.int64` | 列表推导式 + `int()` |
	| 数据来自 NumPy 数组 | 直接用 `.tolist()` |
	| 需要批量处理大量数据 | `.tolist()` 性能最好 |
	| 嵌套列表 | 递归转换函数 |

	---

	## 为什么需要转换？

	- `np.int64` 在 JSON 序列化时会报错（`TypeError: Object of type int64 is not JSON serializable`）
	- 某些第三方库只接受 Python 原生类型
	- 跨进程/跨语言数据传递时需要原生类型

* 如何对 list 中的元素实现 unique 操作

	在 Python 中对 list 实现 unique（去重）操作，有多种方法，根据不同需求选择最合适的。

	---

	## 方法 1：使用 `set()`（最常用、最简洁）

	```python
	# 基本用法
	arr = [1, 2, 2, 3, 3, 4, 5, 5]
	result = list(set(arr))
	print(result)  # [1, 2, 3, 4, 5]（注意：顺序不保证）
	```

	**缺点**：不保留原始顺序。

	---

	## 方法 2：使用 `dict.fromkeys()`（保留顺序，Python 3.7+）

	```python
	arr = [1, 2, 2, 3, 3, 4, 5, 5]
	result = list(dict.fromkeys(arr))
	print(result)  # [1, 2, 3, 4, 5]（保留顺序）
	```

	**优点**：保留原始顺序，性能好。

	---

	## 方法 3：使用列表推导式 + `seen` 集合（手动控制）

	```python
	arr = [1, 2, 2, 3, 3, 4, 5, 5]
	seen = set()
	result = [x for x in arr if not (x in seen or seen.add(x))]
	print(result)  # [1, 2, 3, 4, 5]（保留顺序）
	```

	**优点**：灵活，可以在去重的同时做其他处理。

	---

	## 方法 4：使用 `collections.OrderedDict`（Python 3.6 及以下）

	```python
	from collections import OrderedDict

	arr = [1, 2, 2, 3, 3, 4, 5, 5]
	result = list(OrderedDict.fromkeys(arr))
	print(result)  # [1, 2, 3, 4, 5]（保留顺序）
	```

	---

	## 方法 5：NumPy 数组去重（适合数值型数据）

	```python
	import numpy as np

	arr = [1, 2, 2, 3, 3, 4, 5, 5]
	result = np.unique(arr).tolist()
	print(result)  # [1, 2, 3, 4, 5]
	```

	**优点**：对大量数值数据性能好。
	**注意**：返回结果会自动排序。

	---

	## 方法 6：保留顺序且去重（通用函数）

	```python
	def unique_preserve_order(seq):
		seen = set()
		return [x for x in seq if not (x in seen or seen.add(x))]

	arr = [1, 2, 2, 3, 3, 4, 5, 5]
	result = unique_preserve_order(arr)
	print(result)  # [1, 2, 3, 4, 5]
	```

	---

	## 方法 7：去重并统计出现次数

	```python
	from collections import Counter

	arr = [1, 2, 2, 3, 3, 3, 4, 5, 5]
	counter = Counter(arr)
	unique_items = list(counter.keys())
	counts = list(counter.values())

	print(unique_items)  # [1, 2, 3, 4, 5]
	print(counts)        # [1, 2, 3, 1, 2]
	```

	---

	## 性能对比（处理 100 万条数据）

	| 方法 | 速度 | 是否保留顺序 |
	|------|------|-------------|
	| `set()` | 最快 | ❌ |
	| `dict.fromkeys()` | 很快 | ✅ |
	| 列表推导 + seen | 快 | ✅ |
	| `np.unique()` | 快（数值型） | ❌（自动排序） |
	| `OrderedDict` | 较慢 | ✅ |

	---

	## 针对混合类型数据

	```python
	arr = [1, "1", 2, "2", 1, "1", 3]

	# 方法1：根据类型和值去重
	def unique_mixed(seq):
		seen = set()
		result = []
		for item in seq:
			# 使用 (type, value) 作为去重键
			key = (type(item), item)
			if key not in seen:
				seen.add(key)
				result.append(item)
		return result

	print(unique_mixed(arr))  # [1, '1', 2, '2', 3]
	```

	```python
	class Person:
		def __init__(self, name, age):
			self.name = name
			self.age = age
		
		def __hash__(self):
			return hash((self.name, self.age))
		
		def __eq__(self, other):
			return self.name == other.name and self.age == other.age

	people = [Person("Alice", 25), Person("Bob", 30), Person("Alice", 25)]
	result = list(dict.fromkeys(people))  # 按 name+age 去重
	```

* python 中如何对元素取补集，比如 arr =  [1, 2, 3, 4, 5]，现在我有 arr_1 = [2, 5]，如何得到 arr_2 = [1, 3, 4]

	在 Python 中，对列表取补集（差集）有多种方法，我为你列举几种常用方式：

	## 1. 使用列表推导式（推荐）
	```python
	arr = [1, 2, 3, 4, 5]
	arr_1 = [2, 5]

	# 取出 arr 中不在 arr_1 的元素
	arr_2 = [x for x in arr if x not in arr_1]
	print(arr_2)  # [1, 3, 4]
	```

	## 2. 使用集合（适合元素唯一且顺序不重要）
	```python
	arr = [1, 2, 3, 4, 5]
	arr_1 = [2, 5]

	arr_2 = list(set(arr) - set(arr_1))
	print(arr_2)  # [1, 3, 4]（顺序可能不同）
	```

	## 3. 使用 filter 函数
	```python
	arr = [1, 2, 3, 4, 5]
	arr_1 = [2, 5]

	arr_2 = list(filter(lambda x: x not in arr_1, arr))
	print(arr_2)  # [1, 3, 4]
	```

	## 4. 使用 collections.Counter（支持重复元素）
	```python
	from collections import Counter

	arr = [1, 2, 2, 3, 4, 5]
	arr_1 = [2, 5]

	arr_2 = list((Counter(arr) - Counter(arr_1)).elements())
	print(arr_2)  # [1, 2, 3, 4]
	```

	## 注意事项

	- **列表推导式**：保留原始顺序，适合元素不多的情况
	- **集合运算**：去重且不保留顺序，适合元素唯一且顺序不重要
	- **性能**：如果 arr 很大，将 arr_1 转为 set 可以提高效率：
	```python
	arr_1_set = set(arr_1)
	arr_2 = [x for x in arr if x not in arr_1_set]
	```

	**推荐使用列表推导式**，因为它简单直观，且保留了原始列表的顺序。

	## 场景 1：只绘制 x 轴在某个区间内的数据（最常见）

	如果你已经有完整数据，但只想显示 x 在 `[2, 5]` 之间的部分，有两种方法：

	### 方法 A：用 `plt.xlim()` 设置显示范围（不修改数据）
	```python
	import numpy as np
	import matplotlib.pyplot as plt

	x = np.linspace(0, 10, 200)
	y = np.sin(x)

	plt.plot(x, y, 'b-', linewidth=2)
	plt.xlim(2, 5)   # 只显示 x 在 2~5 之间的部分
	plt.grid(True)
	plt.show()
	```
	**特点**：数据完整保留，只是视图缩放，适合交互式查看。

	---

	### 方法 B：用布尔索引截取数据（真正只取子集）
	```python
	x = np.linspace(0, 10, 200)
	y = np.sin(x)

	# 只取 x 在 [2, 5] 范围内的数据点
	mask = (x >= 2) & (x <= 5)
	x_sub = x[mask]
	y_sub = y[mask]

	plt.plot(x_sub, y_sub, 'r-', linewidth=3)
	plt.grid(True)
	plt.show()
	```
	**特点**：只绘制指定区间的数据，适合后续计算或存图。

	## 场景 2：绘制 y 值在指定范围内的数据（过滤异常值）

	比如只想画 y 在 `[-0.5, 0.5]` 之间的点：

	```python
	x = np.linspace(0, 10, 200)
	y = np.sin(x) * 2   # 范围 -2~2

	# 过滤 y 在 [-0.5, 0.5] 之间的点
	mask = (y >= -0.5) & (y <= 0.5)
	x_filtered = x[mask]
	y_filtered = y[mask]

	plt.plot(x_filtered, y_filtered, 'go', markersize=5, linestyle='None')
	plt.axhline(y=0.5, color='gray', linestyle='--', alpha=0.5)
	plt.axhline(y=-0.5, color='gray', linestyle='--', alpha=0.5)
	plt.grid(True)
	plt.show()
	```

	## 场景 3：同时限制 x 和 y 的范围（最完整）

	```python
	x = np.linspace(0, 10, 300)
	y = np.exp(-x/3) * np.sin(2*x)

	# 同时取 x in [1, 6] 且 y in [-0.3, 0.5]
	mask = (x >= 1) & (x <= 6) & (y >= -0.3) & (y <= 0.5)
	x_final = x[mask]
	y_final = y[mask]

	plt.plot(x_final, y_final, 'b-o', markersize=3, linewidth=1.5)
	plt.grid(True)
	plt.xlabel('x')
	plt.ylabel('y')
	plt.title('Filtered by both x and y range')
	plt.show()
	```

	```python
	x = np.arange(100)
	```

	```python
	x = np.linspace(0, 6, 100)
	```

	## 常见错误提醒

	| 错误写法 | 原因 | 正确写法 |
	|---------|------|---------|
	| `x >= 2 & x <= 5` | 运算符优先级问题 | `(x >= 2) & (x <= 5)` |
	| `mask = (x >= 2 and x <= 5)` | numpy数组不能用 `and` | 必须用 `&` |
	| `plt.xlim(5, 2)` | 范围反了 | `plt.xlim(2, 5)` |
