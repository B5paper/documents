* 数字电子技术基础

    * 数制

        十进制：$143.75 = 1 \times 10^2 + 4 \times 10^1 + 3 \times 10^0 + 7 \times 10^{-1} + 5 \times 10^{-2}$

        任意一个十进制数 $D$ 均可展开为

        $$D = \sum k_i \times 10^i$$

        其中 $k_i$ 是第 i 位的系数，它可以是 0 ~ 9 这十个数码中的任何一个。

        注：

        1. 有时候会看到对任意一个十进制数的数学表示的要求，这里记录一下。最低位是 n 的 0 次方，再往后是 -1 次方，-2 次方...

        十进制数转换为二进制数：

        使用短除法，除以 2，得到的余数则为二进制从低位到高位的数码。

        十进制小数转换为二进制数，乘以 2，得到的整数部分即二进制小数的最高位。直到十进制小数位为 0。

        **二进制算数运算的两个特点：**

        1. 二进制数的乘法运算可以通过若干次的“被乘数（或零）左移 1 位”和“被乘数（或零）与部分积相加”这两种操作完成

        2. 二进制数的除法运算能通过若干次的“除数右移 1 位”和“从被除数或余数中送去除数”这两种操作完成

        注：

        1. 在这里提示这个东西，可能是为后面乘法器和除法器的设计做准备

    * 反码、补码和补码运算

        原码：在二进制数的前面增加一位符号位。符号位为 0 表示这个数是正数，符号位为 1 表示这个数是负数。

        在舍弃进位的条件下，减去某个数可以用加上它的补码来代替。

        对于有效数字（不包括符号位）为 n 位的二进制数 N，它的补码$(N)_{comp}$表示方法为

        $$(N)_{comp} = \left\{ \begin{aligned} N, \ (当 N 为正数) \\ 2^n - N, \ (当 N 为负数) \end{aligned}  \right.$$

        即正数的补码与原码相同，负数的补码为 $2^n - N$，符号位保持不变。

        example:

        * 给出十进制数 -19 的二进制原码，补码

			十进制数 -19 的二进制表示如下（假设用 8 位表示）：

			**1. 原码：**
			- 先写出 19 的二进制：`0001 0011`
			- 因为是负数，符号位为 1：  
			  **原码 = 1001 0011**

			**2. 补码：**
			- 原码：`1001 0011`
			- 除符号位外，其余各位取反：`1110 1100`
			- 末位加 1：`1110 1101`

			**补码 = 1110 1101**

			所以：
			- 原码：`1001 0011`
			- 补码：`1110 1101`gvgvgojkkkkkkkkkkkkkjjj

		* 为什么使用 8 位表示？使用 7 位不行吗？

			可以用 7 位，但**7 位补码能表示的范围是 -64 到 +63**，-19 在其中，所以 7 位完全可以表示 -19。

			不过要注意：**7 位表示时，符号位占 1 位，数值位只有 6 位**，所以：

			- 7 位原码范围：`-63 ~ +63`（因为 `1111111` 是 -63，`1000000` 是 -0）
			- 7 位补码范围：`-64 ~ +63`

			**-19 的 7 位表示：**

			1. 先写 19 的 6 位二进制：`010011`
			2. **原码**（符号位 1 + 6 位数值）：`1 010011` → **1010011**
			3. **补码**：原码除符号位取反得 `1101100`，末位加 1 → **1101101**

			所以 7 位时：
			- 原码：`1010011`
			- 补码：`1101101`

			**那为什么前面用 8 位？**

			因为实际计算机中**字节是最小寻址单位，通常是 8 位**，所以讲原码/补码时默认用 8 位、16 位、32 位这种“整字节”宽度。8 位只是**习惯上的默认示例宽度**，不是必须的。

			总结：
			- **7 位可以表示 -19**，原码 `1010011`，补码 `1101101`。
			- 用 8 位是因为计算机通常按字节（8 位）存储，示例更贴近实际。
			- 位数越少，能表示的范围越小；只要范围够，用几位都行，但必须是“符号位 + 数值位”的固定宽度。

		* 那么十进制小数的二进制补码怎么求？

			小数（定点小数）的补码和整数思路一样，但**小数点的位置固定在小数点前（符号位之后）**，需要区分“定点小数”的表示格式。

			## 一、定点小数的补码定义

			假设用 **1 位符号位 + n 位小数位** 表示定点小数（纯小数），格式为：

			```
			S . x₁x₂…xₙ
			```

			- **原码**：符号位 + 绝对值的小数二进制
			- **补码**：
			  - 正数：补码 = 原码
			  - 负数：**原码除符号位外各位取反，末位（最低位）加 1**（和整数一样）
			  - 或者用定义：`[x]补 = 2 + x`（x 为负纯小数，mod 2）

			## 二、举例：求 -0.1011 的补码（用 1 位符号 + 4 位小数）

			**1. 原码：**
			- 0.1011 的二进制就是 `0.1011`
			- 负数符号位为 1：  
			  **原码 = 1.1011**

			**2. 补码：**
			- 原码 `1.1011`
			- 除符号位取反：`1.0100`
			- 末位加 1：`1.0101`

			**补码 = 1.0101**

			验证：`1.0101` 按补码解释 = `-1 + 0.0101₂ = -1 + 0.3125 = -0.6875`，而 `-0.1011₂ = -0.6875`，正确。

			## 三、如果小数不是纯小数（有整数部分）

			比如 -19.625，通常做法是**整数部分和小数部分分别处理，或者整体转成定点数**。常见两种方式：

			### 方式 1：整数、小数分开求补码
			- 整数部分 -19 → 补码 `11101101`（8 位）
			- 小数部分 0.625 = 0.101₂ → 正数补码就是 `0.101`
			- 拼接：`11101101.101`

			但这种方式在计算机里不常用，因为整数和小数宽度要事先约定。

			### 方式 2：定点数整体表示（推荐理解方式）
			把所有数统一乘 2^k 变成整数，再求补码。例如用 8 位整数 + 3 位小数表示 -19.625：
			- `19.625 × 8 = 157`，但 8 位补码范围 -128~127，不够，需要更宽。
			- 用 9 位：`-19.625 × 8 = -157`，9 位补码可表示 -256~255。
			- -157 的 9 位补码：157 = `010011101`，取反加 1 → `101100011`
			- 加上小数点（低 3 位是小数）：`101100.011`

			## 四、关键点总结

			| 项目 | 说明 |
			|------|------|
			| 定点小数补码 | 符号位 + 小数位，负数“取反加 1”（末位加 1） |
			| 正数 | 补码 = 原码 |
			| 负数 | 原码除符号位取反，最低位加 1 |
			| 定义法 | `[x]补 = 2 + x`（mod 2，纯小数） |
			| 有整数部分 | 通常整体乘 2^k 转整数求补码，或整数/小数分开处理 |
			| 注意 | 小数点位置必须事先约定（定点格式），否则补码无意义 |

			**最简记法：小数补码 = 把小数当成“小数点固定在符号位后”的整数来求补码，规则和整数完全一样，只是最后把小数点放回去。**

	* 详细讲讲格雷码

		格雷码（Gray Code）是一种二进制编码方式，其核心特点是**任意两个相邻的编码之间只有一位二进制数不同**。这个特性使它在数字电路、位置检测、纠错等领域有广泛应用。

		---

		## 一、基本定义

		格雷码是一种循环二进制单位距离码。对于 n 位格雷码，共有 2ⁿ 个码字，相邻码字（包括首尾）之间恰好只有一位不同。

		### 1 位格雷码
		```
		0
		1
		```
		相邻（0→1）只有一位不同，首尾（1→0）也只有一位不同。

		### 2 位格雷码
		```
		00
		01
		11
		10
		```
		验证：00→01（第2位变），01→11（第1位变），11→10（第2位变），10→00（第1位变）。全部满足。

		### 3 位格雷码
		```
		000
		001
		011
		010
		110
		111
		101
		100
		```

		### 4 位格雷码
		```
		0000
		0001
		0011
		0010
		0110
		0111
		0101
		0100
		1100
		1101

		1011
		1001
		```

		## 二、构造方法

		### 1. 递归法（镜像法）

		这是最经典的构造方法：

		- **1 位格雷码**：`0, 1`
		- **n 位格雷码**由 n-1 位格雷码构造：
		  1. 在 n-1 位格雷码前面加 `0`，得到前半部分；
		  2. 将 n-1 位格雷码**逆序**，前面加 `1`，得到后半部分；
		  3. 拼接。

		以 2 位为例：
		- 1 位：`0, 1`
		- 前半：`00, 01`
		- 逆序 1 位：`1, 0` → 加 1：`11, 10`
		- 结果：`00, 01, 11, 10` ✓

		以 3 位为例：
		- 2 位：`00, 01, 11, 10`
		- 前半：`000, 001, 011, 010`
		- 逆序 2 位：`10, 11, 01, 00` → 加 1：`110, 111, 101, 100`
		- 结果：`000, 001, 011, 010, 110, 111, 101, 100` ✓

		### 2. 公式法（二进制→格雷码）

		设二进制数为 \( B = b_{n-1}b_{n-2}\cdots b_1b_0 \)，对应的格雷码为 \( G = g_{n-1}g_{n-2}\cdots g_1g_0 \)，则：

		\[
		g_{n-1} = b_{n-1}
		\]
		\[
		g_i = b_{i+1} \oplus b_i \quad (0 \le i < n-1)
		\]

		即**格雷码的最高位与二进制最高位相同，其余每一位是二进制中该位与高一位的异或**。

		**例**：二进制 `1011` →
		- g3 = b3 = 1
		- g2 = b3⊕b2 = 1⊕0 = 1
		- g1 = b2⊕b1 = 0⊕1 = 1
		- g0 = b1⊕b0 = 1⊕1 = 0

		格雷码：`1110`

		### 3. 公式法（格雷码→二进制）

		反过来，已知格雷码 \( G \)，求二进制 \( B \)：

		\[
		b_{n-1} = g_{n-1}
		\]
		\[
		b_i = b_{i+1} \oplus g_i \quad (0 \le i < n-1)
		\]

		即**二进制最高位等于格雷码最高位，其余每一位是二进制高一位与该位格雷码的异或**（从高位向低位递推）。

		**例**：格雷码 `1110` →
		- b3 = g3 = 1
		- b2 = b3⊕g2 = 1⊕1 = 0
		- b1 = b2⊕g1 = 0⊕1 = 1
		- b0 = b1⊕g0 = 1⊕0 = 1

		二进制：`1011` ✓

		## 三、重要性质

		1. **相邻性（单位距离性）**：任意相邻码字只有一位不同，包括首尾循环相邻。
		2. **循环性**：首尾码字也只有一位不同，因此格雷码可以构成一个循环。
		3. **反射性**：n 位格雷码的后半部分是前半部分的镜像（除最高位外）。
		4. **唯一性**：标准格雷码（二进制反射格雷码）是确定的，但格雷码不唯一——只要满足相邻一位不同的编码都叫格雷码。
		5. **非加权码**：格雷码不是加权码，不能直接按位权求和得到数值。
		6. **汉明距离**：相邻码字汉明距离为 1。

		## 四、应用场景

		### 1. 旋转编码器 / 位置传感器

		这是格雷码最经典的应用。在绝对式旋转编码器中，码盘上刻有格雷码图案。当码盘旋转时，读数每次只变化一位。

		**为什么重要**：如果用普通二进制，某些位置切换时可能多位同时变化（如 0111→1000，四位全变）。由于各传感器物理位置有微小偏差，多位同时变化可能导致瞬间读到错误码（如 1111），产生巨大误差。格雷码保证每次只变一位，最多只差一个最小单位，不会出现灾难性错误。

		### 2. 数字电路中的时钟域交叉

		在多时钟域系统中，计数器值跨时钟域传递时，如果使用二进制计数器，多位同时变化可能被采样到中间错误值。使用格雷码计数器（如异步 FIFO 的读写指针），每次只变一位，采样结果要么是旧值要么是新值，不会出现非法中间状态。

		### 3. 异步 FIFO 的空满判断

		异步 FIFO 中读写指针跨时钟域比较，指针用格雷码编码，确保跨域采样安全。空满判断通过比较格雷码指针实现。

		### 4. 卡诺图

		卡诺图的行列标号采用格雷码顺序排列，使得相邻格子只有一个变量不同，从而可以化简逻辑表达式。

		### 5. 纠错编码

		格雷码可用于某些纠错码构造中，因为相邻码字距离小，便于分析错误模式。

		### 6. 遗传算法

		遗传算法中常用格雷码编码染色体，因为格雷码的相邻性使小步变异不会导致数值大幅跳变，有利于局部搜索。

		### 7. 低功耗编码

		由于相邻状态只有一位翻转，格雷码计数器在状态切换时翻转的位数最少，可降低动态功耗。

		---

		## 五、格雷码计数器

		格雷码计数器是一种每次只翻转一位的计数器。实现方式通常有两种：

		1. **二进制计数器 + 二进制→格雷码转换**：内部用二进制计数，输出前转换为格雷码。
		2. **直接格雷码状态机**：根据当前格雷码和方向，直接计算下一状态。

		在异步 FIFO 中，读写指针通常采用第一种方式：二进制指针加一后转换为格雷码输出到另一时钟域，另一侧采样后再转回二进制进行比较。

		## 七、扩展：其他类型的格雷码

		标准格雷码（二进制反射格雷码，BRGC）是最常用的一种，但还存在其他满足"相邻一位不同"的编码：

		- **平衡格雷码**：使 0 和 1 的分布更均匀。
		- **n 进制格雷码**：推广到多进制，相邻码字只有一位数字变化。
		- **贝克特-格雷码**：用于某些调度问题。

		但在工程实践中，提到"格雷码"通常默认指二进制反射格雷码。

		## 八、总结

		| 要点 | 内容 |
		|------|------|
		| 核心特性 | 相邻码字只有一位不同（汉明距离为 1） |
		| 构造方法 | 镜像递归法、二进制异或公式法 |
		| 关键公式 | 二进制→格雷码：\( g_i = b_{i+1} \oplus b_i \)（最高位 \( g_{n-1}=b_{n-1} \)） |
		| 主要应用 | 旋转编码器、异步 FIFO 指针、跨时钟域传输、卡诺图、低功耗计数 |
		| 本质优势 | 消除多位同时翻转带来的瞬态错误和功耗问题 |

		格雷码的精髓在于**用"一位变化"换取状态切换的安全性**，这在任何存在物理偏差、异步采样或功耗约束的场景中都具有重要价值。
