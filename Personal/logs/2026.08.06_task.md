* [ ] 使用 `fzf` 实现模糊补全

    ```bash
    # 在 ~/.bashrc 中
    ff() {
        local file
        file=$(find . -type f 2>/dev/null | fzf --height 40% --preview 'head -50 {}')
        if [[ -n $file ]]; then
            # 去掉 ./ 前缀
            echo "${file#./}"
            # 或者直接打开文件
            # vim "${file}"
        fi
    }
    ```

    使用：

    ```bash
    ff
    ```

    会弹出交互式选择框，输入文件名模糊匹配，回车即可。
