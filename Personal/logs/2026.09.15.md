* screen 如何删除一个 session

    在 `screen` 中删除（终止）一个 session 有以下几种方法：

    ## 1. 在 session 内部退出（推荐）

    如果你当前正在某个 screen session 里：

    ```bash
    exit
    ```
    或按快捷键：
    ```
    Ctrl + A, 然后按 K
    ```
    然后按 `y` 确认，即可杀掉当前 session。

    ## 2. 从外部杀掉指定 session

    先列出所有 session：
    ```bash
    screen -ls
    ```

    输出示例：
    ```
    There are screens on:
        12345.pts-0.hostname    (Detached)
        67890.pts-1.hostname    (Attached)
    ```

    然后杀掉指定 session：
    ```bash
    screen -S 12345 -X quit
    ```
    或：
    ```bash
    screen -S 12345.pts-0.hostname -X quit
    ```

    ## 3. 杀掉所有 session

    ```bash
    screen -ls | grep Detached | cut -d. -f1 | awk '{print $1}' | xargs kill
    ```

    或者：
    ```bash
    pkill screen
    ```

    ## 4. 强制杀掉（会话卡死时）

    ```bash
    kill -9 <PID>
    ```

    PID 就是 `screen -ls` 中显示的进程号。

    ## 常用组合

    | 操作 | 命令 |
    |------|------|
    | 列出 session | `screen -ls` |
    | 进入 session | `screen -r <name/PID>` |
    | 分离 session | `Ctrl+A, D` |
    | 杀掉 session | `screen -S <name/PID> -X quit` |

    **注意**：`screen -wipe` 只能清理已经死掉的 session 记录，不能删除正在运行的 session。

* 详细讲讲 Plug 'VimWei/vim9-toc' 的用法

    `VimWei/vim9-toc` 插件为 Vim 提供了一个统一的交互式目录（TOC）入口。无论你是在编辑 Markdown、LaTeX 还是普通的 YAML、TOML 文件，都可以通过一条命令 `:Toc` 调出层级目录并快速跳转。

    ### 核心用法与安装

    它的设计理念是 “一条命令，适配所有文件类型”。安装方式如下：

    *   **vim-plug 用户**：在配置文件中添加 `Plug 'VimWei/vim9-toc'` 并运行 `:PlugInstall`。
    *   **原生包管理用户**：
        ```bash
        mkdir -p ~/.vim/pack/toc/start
        cd ~/.vim/pack/toc/start
        git clone https://github.com/VimWei/vim9-toc.git
        ```

    ### 它是如何工作的

    `:Toc` 命令会根据当前缓冲区的类型智能选择生成目录的策略：
    1.  **内置支持**：对于 Vim help、Markdown、LaTeX、HTML、AsciiDoc 等结构化格式，它会**委托给 Vim 内置的 helptoc 机制**来处理。
    2.  **折叠驱动**：对于其他支持折叠的文件类型（如 TOML, YAML, JSON, Git, Vim Script），它会**基于 Vim 自身的折叠（folding）功能**来生成大纲。
    3.  **缩进兜底**：如果文件没有折叠功能，它会退而求其次，基于**缩进层级**来构建一个简单的目录。

    ### 交互式弹窗操作

    执行 `:Toc` 会弹出一个交互式窗口。虽然按键映射可能与你熟悉的略有不同，但基本逻辑是一致的。以下为内置 `helptoc` 的按键逻辑，`vim9-toc` 的操作体验与此高度互通：
    *   **导航**：`j` / `k` 上下移动，`J` / `K` 移动并**直接跳转**到主缓冲区对应行。
    *   **折叠/展开**：`H` 折叠一层，`L` 展开一层。
    *   **快速定位**：`c` 跳转到光标处最近的条目，`g` / `G` 跳到首尾。
    *   **退出**：`q` 关闭弹窗。

    ### 进阶：自定义收集器

    该插件最强大的特性之一是**可扩展性**。如果你希望为某个特定文件类型（假设是 `foobar`）定义专属的目录生成规则，可以使用 `toc#AddCollector()` 函数。这允许你自定义解析逻辑，将符合特定正则的行提取为 TOC 条目。

    ### 注意事项
    该插件需要 **Vim 9.1** 或更高版本（其内部使用 Vim9 脚本编写以实现更快的执行效率），并已在 2026 年 8 月发布了初始版本 。
