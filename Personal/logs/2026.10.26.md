* vim-markdown 插件的折叠，只支持按 # 标题折叠，不支持按 * 无序列表折叠

* 在 fold　过程中，有时遇到内容中有 # 开头的标题，不会按 indent 折叠，这是因为 vim 默认设置了``setlocal foldignore=#`。

    比如：

    ```
    * unordered list

        # this is a title

        other content

        another content
    ```

    经过折叠后变成：

    ```
    * unordered list

        # this is a title

        folding line
    ```

    此时可以设置`setlocal foldignore=`，解决这个问题。
