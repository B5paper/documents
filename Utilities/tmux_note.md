## cache

* tmux 如何进入复制模式

    在 `tmux` 中，进入复制模式最常用的方法是按下 **`Ctrl+b`**，然后松开，再按下 **`[`** 键。

    `Ctrl+b` 是 `tmux` 的默认前缀键（Prefix），后面的 `[` 命令会激活复制模式，让你可以自由滚动窗口的历史输出并选择文本进行复制。

    **📋 进入复制模式后，如何选择并复制文本？**

    你可以在复制模式中，像在 `Vim` 或 `Emacs` 编辑器中一样移动光标和选择文本。

    默认操作流程如下：

    1.  **进入模式**：按下 `Ctrl+b`，然后按 `[`。
    2.  **移动光标**：使用方向键（↑↓←→）或 `Page Up` / `Page Down` 键浏览历史内容。
    3.  **开始选择**：将光标移到想复制文本的起点，按下 **`Space`**（空格键）开始高亮选择。
    4.  **移动并选定**：移动光标到想复制文本的终点，高亮区域会随之变化。
    5.  **完成复制**：按下 **`Enter`** 键，选中的文本就会被复制到一个粘贴缓冲区中。
    6.  **退出模式**：按 **`q`** 键退出复制模式。

    复制完成后，你可以按 **`Ctrl+b`**，然后按 **`]`** 键，将最近复制的内容粘贴到当前光标位置。

    如果你在使用 `Vim` 风格的快捷键，也可以在 `.tmux.conf` 配置文件中自定义复制模式下的按键（如使用 `v` 键开始选择，`y` 键复制等），让它更符合你的操作习惯。

* tmux 如何恢复 session

    恢复 tmux session (会话) 主要有两种场景，分别对应不同的方法：

    ### 🔌 场景一：只是断开了连接，想重新连回去

    这种情况最常用。当你的终端关闭或网络断开后，之前开启的 tmux 会话其实还在后台运行，你需要做的只是重新“连”上去。

    1.  **查看所有会话**：先用这个命令看看当前有哪些会话在运行：
        ```bash
        tmux list-sessions
        # 或者使用简写
        tmux ls
        ```
        输出结果类似于 `0: 2 windows (created ...)`，其中 `0` 就是会话的名称或编号。

    2.  **连接到一个会话**：
        *   **连接到指定会话**（把 `<name>` 换成你查到的会话名或编号）：
            ```bash
            tmux attach -t <name>
            ```
            这个命令的简写形式是 `tmux a -t <name>`。
        *   **快速连接到上一个会话**：如果只有一个会话，或者想连到最近使用的那个，直接运行：
            ```bash
            tmux attach
            # 或
            tmux a
            ```
            即可。

    **快捷键**：在 tmux 内部，你可以按 **`prefix + s`**（默认 prefix 是 `Ctrl+b`）来调出一个会话列表，用键盘选择后按回车即可切换。

    ### 💾 场景二：电脑重启了，想恢复之前的工作环境

    如果系统重启，tmux 的会话信息（比如窗口布局、运行的程序）默认会丢失。要恢复这种状态，需要借助第三方插件，最主流的是 **tmux-resurrect**。

    它可以将你的整个 tmux 环境（包括会话、窗口、面板布局、当前路径，甚至一些运行中的程序）保存下来，并在重启后一键恢复。

    *   **安装**：推荐通过 Tmux Plugin Manager (TPM) 安装。在 `~/.tmux.conf` 中加入配置，然后按 `prefix + I` 安装。
    *   **使用方法**：安装后，你可以在 tmux 中使用以下快捷键：
        *   **`prefix + Ctrl-s`**：保存当前所有会话的状态。
        *   **`prefix + Ctrl-r`**：恢复之前保存的会话环境。

    > 注意：`tmux-resurrect` 默认只恢复一部分常用程序（如 `vi`, `top`, `irssi` 等）。如果需要恢复 Vim/Neovim 的会话或其他程序，需要额外配置。

* tmux 如何强制关闭 session 中的某个 screen

    在 tmux 中，**没有“screen”这个概念**，你指的应该是 **窗格（Pane）** 或 **窗口（Window）**。我分情况教你如何强制关闭：

    ---

    ### 1️⃣ 强制关闭当前的 **窗格（Pane）**

    如果你在某个窗格里卡住了，想直接杀掉它：

    - **快捷键**：按 **`prefix + x`**（默认 `prefix` 是 `Ctrl+b`），然后按 `y` 确认。
    - **命令行法**：在 tmux 内部运行：
      ```bash
      exit
      ```
      如果进程卡死，`exit` 没用，就按上面的快捷键。

    **强制杀死（不提示）**：在命令行直接执行（不进入 tmux）：
    ```bash
    tmux kill-pane -t <session名>:<窗口编号>.<窗格编号>
    ```
    例：杀死 session `0` 中窗口 `1` 里的第 `2` 个窗格：
    ```bash
    tmux kill-pane -t 0:1.2
    ```

    ---

    ### 2️⃣ 强制关闭整个 **窗口（Window）**

    窗口里可能有多个窗格，一次全关掉：

    - **快捷键**：按 **`prefix + &`**，然后按 `y` 确认。
    - **命令行法**（不进入 tmux）：
      ```bash
      tmux kill-window -t <session名>:<窗口编号>
      ```
      例：杀死 session `0` 里的窗口 `2`：
      ```bash
      tmux kill-window -t 0:2
      ```

    ---

    ### 3️⃣ 如果进程卡死，连快捷键都无效

    用 **更暴力的方式**——直接通过系统信号杀死该窗格里的进程：

    ```bash
    tmux send-keys -t <目标窗格> C-c
    ```
    这会向该窗格发送 `Ctrl+C` 中断信号，多数情况能救回来。

    还不行的话，用系统 `kill` 命令找到对应进程：
    ```bash
    tmux list-panes -a -F "#{pane_pid} #{session_name}:#{window_index}.#{pane_index}"
    ```
    根据列出的 PID，直接 `kill -9 <PID>`。

    ---

    ### 📌 常用技巧

    - **查看所有窗格编号**：按 `prefix + q`，会在每个窗格上短暂显示编号。
    - **查看所有窗口编号**：按 `prefix + w`，会弹出列表。

    ---

    如果你说的“screen”指的是 **GNU Screen**（而不是 tmux 的窗格），那就完全不是一回事了——GNU Screen 里关闭窗口的快捷键是 `Ctrl+a k`。请确认一下你用的是哪个，我可以再给你针对性的命令。
